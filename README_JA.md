# DeployFlow

**デプロイ手順の可視化、SSH ターミナル、SFTP ファイル管理をまとめた Windows デスクトップツール。**

[English](README.md) · [简体中文](README_CN.md) · [繁體中文](README_TW.md) · [日本語](README_JA.md) · [한국어](README_KO.md) · [Español](README_ES.md)

## DeployFlow が解決すること

個人開発や小規模チームでは、少数のプロジェクトを公開するために、本格的な自動化基盤の構築・設定・保守まで行うのは負担になることがあります。一方、ターミナルだけで作業すると、同じコマンドの入力、パスのコピー、転送画面の切り替えを繰り返し、手順を抜かしてしまうこともあります。

DeployFlow は既存のツールとスクリプトを、再利用できるデスクトップ上の手順にまとめます。ビルド、接続、アップロード、スクリプト実行、ヘルスチェックを順に行い、そのままターミナルとファイル画面で結果を確認できます。

**個人開発者、小規模チーム、Linux サーバーへのデプロイや調査を日常的に行う開発者**向けです。Java サービスやフロントエンドの公開、日常のサーバー操作に使えます。集中スケジューリング、複数人による承認、分散実行は現在の対象外です。

![デプロイフローとパラメーター](docs/screenshots/workflow.png)

*例：Maven ビルド → 接続 → アップロード → スクリプト → ヘルスチェック。画像は英語 UI です。ユーザーの内容やコマンド出力は原文のままです。*

## チェックリストを再利用可能なフローに

順序付きのステップでタスクを作成します。クリックで設定を確認、ダブルクリックで編集、ドラッグで並べ替えます。選択中のステップがあればその後に追加し、なければ末尾に追加します。フローとパラメーターパネルは個別にも同時にも表示できます。

| ステップ | 内容 |
| --- | --- |
| サーバー接続 | 保存済み設定から名前付き SSH 接続を作成。 |
| ブランチのマージ／プッシュ | 設定に従って Git の pull、merge、commit、push を実行。 |
| Maven ビルド | プロジェクトをビルドし、後でアップロードする JAR を識別。 |
| ローカルコマンド／スクリプト | 作業ディレクトリ、タイムアウト、スクリプト引数を指定して実行。 |
| アップロード | 成果物、ファイル、フォルダーを転送。保存先作成と既存ファイルのバックアップは任意。 |
| リモートコマンド／スクリプト | 指定した接続でコマンドや Shell スクリプトを実行。 |
| 待機 | 指定した秒数だけ停止。 |
| ヘルスチェック | コマンドを繰り返し、連続成功回数またはタイムアウトで判定。 |

未選択で **Run** を押すと全体を実行し、選択済みなら選択したステップを元の順序で実行します。右クリックでは単独実行や指定位置からの実行も可能です。進捗、出力、エラーを確認し、実行を停止できます。

部分実行で省略した依存ステップは自動実行されません。必要な接続やビルドのステップも同じ実行に含めてください。

## ターミナルに表示されたパスを直接操作

- **Ctrl＋ホバー**：マウスポインターの下にある認識可能なパスに下線を表示。
- **Ctrl＋左クリック**：ディレクトリならターミナルと下部のファイル画面を同時に移動。ファイルなら親ディレクトリに移動。
- **パスを右クリック**：テキストを選択しても、選択せずパスを直接右クリックしても、識別後に対応する操作を表示。
- **ファイル操作**：テキスト編集、引数付きスクリプト実行、権限変更、ログの追尾、末尾 N 行の表示、キーワード検索。

パスは接続先で解決できる必要があります。相対名にはディレクトリ情報が必要で、各 SSH タブがそれぞれのコンテキストを保持します。

![ターミナルと連動するファイル画面](docs/screenshots/remote-files.png)

## 接続情報とよく使う場所

アドレス、ポート、アカウント、認証情報をフォームで管理します。パスワードと秘密鍵の情報を保持し、選択した認証方式を使用します。サーバーごとに複数のディレクトリと任意のコマンドを保存し、既定の場所を設定したり、特定の場所へ直接接続したりできます。

![サーバー接続設定](docs/screenshots/server-config.png)

パスワード保護と **Hide IP** を備えています。対応するアドレス表示では `192.168.10.25` を `192.**.**.25` と表示し、実際の接続には元の値を使います。編集時は非表示設定を解除してください。保存済みログや任意のリモート出力を匿名化する機能ではありません。

## SSH とサーバー監視

タブ横の **+** から別の保存済みサーバーを開けます。エディター下のターミナルと、広い **Terminal mode** を切り替えられます。Qt WebEngine と xterm.js を使用し、Shell 補完、履歴、コピー／貼り付け、中断、再接続に対応します。

左側には Linux の OS、カーネル、稼働時間、負荷、CPU、メモリー、スワップ、ディスク、実行中プログラムのポートや使用量、コマンド情報を表示します。

![SSH とサーバー情報](docs/screenshots/ssh-monitor.png)

プロセスの停止と再起動を試す操作があります。再起動は**非推奨**です。元の起動スクリプト、パイプ、ログのリダイレクトを完全には復元できないため、それらが必要な場合は元のスクリプトやサービス管理機能を使ってください。

## 2 種類のファイル管理画面

**2 ペインの SFTP ウィンドウ**では左側にローカルドライブ、右側にサーバーを表示します。選択項目のアップロードや、ローカル一覧・Windows エクスプローラーからのドラッグに対応します。

![ローカルとリモートのファイル転送](docs/screenshots/sftp-transfer.png)

**組み込みファイルパネル**はターミナルの下にあり、ツリー、パンくず、訪問履歴、ファイル詳細を表示します。隣の **Logs** タブでは現在の接続ログを確認できます。

アップロード／ダウンロード、リモートのコピー／切り取り／貼り付け、名前変更、削除、ファイル・フォルダー作成、権限変更、別ウィンドウでのテキスト編集に対応します。リモートのクリップボードは同じサーバー接続識別子の範囲で使用します。複数の転送を管理でき、実行中の項目を削除するとキャンセルします。完了後は保存場所を開けます。リモートファイルをエクスプローラーのフォルダーにドラッグして、その場所へダウンロードすることもできます。

## スクリプト、変更履歴、ログ

保存したスクリプトをタスクから参照できます。ローカルは `.bat`、`.cmd`、`.ps1`、`.sh`、`.bash`、リモートフローは `.sh`、`.bash` に対応します。

![スクリプトエディター](docs/screenshots/script-editor.png)

タスク、設定、スクリプトは下書きを自動保存し、**Save／Ctrl＋S** で正式ファイルに反映します。変更履歴はプレビュー、復元、複数選択、削除に対応します。アプリ内で設定やスクリプトの名前を変更すると、現在の JSON フロー、下書き、フロー履歴の参照を更新します。

実行ログと SSH ログは日付別に保存され、ファイル名には作成時刻、各記録にはタイムスタンプが付きます。画面の出力を消しても、ログ画面から閲覧・削除できます。

![保存されたログ](docs/screenshots/logs.png)

## はじめに

Windows 64 ビット向けで、開発環境は Python 3.12 です。リモート操作には SSH／SFTP が必要です。監視とリモートスクリプトは主に Linux 向けです。使用するステップに応じて Git、JDK、Maven または Maven Wrapper、Node.js／npm、ローカル Shell 用 Bash を用意してください。

プロジェクトのルートで実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\start.bat
```

IDE や直接起動の場合：

```powershell
.\.venv\Scripts\python.exe app\qt_main.pyw
```

ポータブル版はフォルダー全体を保持し、`DeployFlow.exe` を実行します。まずサーバーとスクリプトを保存し、タスクのステップ、接続名、成果物の参照、作業ディレクトリを設定して保存・実行します。

フロントエンドの例：**ローカルスクリプト → 接続 → フォルダー転送 → リモートコマンド → ヘルスチェック**。バッチの `%CD%` は現在の作業ディレクトリ、`%~dp0` はスクリプト自身の場所です。

## 操作と表示設定

| 場所 | 操作 |
| --- | --- |
| フロー | ダブルクリックで編集、ドラッグで順序変更、Ctrl＋クリックで複数選択、空白部分をドラッグして範囲選択。 |
| キャンバス | ホイールで拡大縮小、右ボタンを押してドラッグすると移動。 |
| 編集 | Ctrl＋S で保存。パラメーター／テキスト欄の Ctrl＋ホイールで文字サイズを変更・記憶。 |
| リモートファイル | Ctrl＋C／X／V、Delete、F2、Ctrl＋A。 |
| 変更履歴 | Ctrl＋クリック、Shift＋クリック、Ctrl＋A。 |

英語、簡体字中国語、繁体字中国語、日本語、韓国語、スペイン語に対応します。初回は英語、以降は保存した言語を使い、再起動なしで切り替えます。ユーザーの内容と外部出力は翻訳しません。白、黒、紙色の黄、緑、カスタム配色があり、パネルサイズ、タスクのズーム、文字サイズを記憶します。

## データと注意事項

データはソースまたは EXE の隣の `conf/` に保存され、必要なフォルダーは自動作成されます。書き込み権限が必要です。

```text
conf/
├── tasks/          # version 2 JSON、拡張子 .txt
├── host/           # サーバー設定
├── scripts/        # スクリプト
├── .drafts/        # 下書き
├── .history/       # 履歴
├── .logs/          # 日付別ログ
├── .cache/         # キャッシュ
├── downloads/      # 既定のダウンロード先
├── known_hosts     # SSH ホスト鍵
└── settings.json   # 言語、表示、設定
```

- 旧 `STEP_xxx=...` 形式は非対応です。アプリ外での名前変更は参照に反映されません。
- 接続設定の既定パスとコマンドは対話接続用です。フローの作業ディレクトリは別に設定します。
- 転送前バックアップは任意です。後続処理の失敗でリリース全体を自動ロールバックしません。
- パスワード保護は Windows ユーザーに紐付きます。別 PC やアカウントでは再入力が必要になる場合があります。
- `conf/` は Git 対象外です。安全に個別バックアップしてください。IP 非表示でもログには実際のアドレスが含まれ得ます。

## ビルドとライセンス

`build.bat` で `release/DeployFlow/` にポータブル版を生成します。Inno Setup 6 を用意して `build_installer.bat` を実行すると `installer-output/` にインストーラーを生成します。インストール後も `conf/` への書き込み権限が必要です。

PySide6、Qt WebEngine、xterm.js、Fabric／Paramiko を使用しています。本体は [MIT License](LICENSE)、依存関係は各ライセンスに従います。ターミナル関連のライセンスは [app/resources/xterm](app/resources/xterm/) にあります。[中国語の紹介文](docs/PROJECT_OVERVIEW_CN.md)も用意しています。
