# 界面语言

支持简体中文、繁体中文、英语、日语、韩语和西班牙语。翻译均在本地完成，不访问网络，也不会翻译用户文件、命令和服务器输出。

首次启动或没有有效语言记录时，默认使用英语。选择结果记录在现有数据目录的 `conf/settings.json` 的 `language` 字段中，后续启动优先使用该记录。

左侧“语言”入口位于“主题”上方，不需要管理员密码。修改保存后立即生效，不重建窗口、不重连服务器，也不会改写用户文件或编辑内容。

## 扩展词条

- 界面使用 `tr("中文原文")`，动态值使用 `tr("说明：{0}", value)`。
- 简体中文直接显示原文；其他语言分别维护在 `en.py`、`zh_tw.py`、`ja.py`、`ko.py`、`es.py` 中。
- 各语言的键及格式占位符应保持一致。未提供翻译时先回退英语，再回退原文。
- 新增语言时，在 `__init__.py` 中导入词条文件，注册 `LANGUAGES`、`_CATALOGS`。
- `qt.py` 负责加载 Qt 自带翻译及设置标准对话框按钮文字。
- `widgets.py` 为界面控件保留 `tr()` 原文和参数，切换语言时仅刷新这些文字；用户输入不参与翻译。新增需要实时切换的控件，应从此模块导入对应控件。
