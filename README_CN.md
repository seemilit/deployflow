# DeployFlow

DeployFlow 是一个基于 PySide6 的 Windows 图形化部署辅助工具。它将部署任务、服务器参数和脚本集中管理，帮助你通过 SSH 更稳定地完成构建、上传、远程执行和服务发布。

## 主要功能

- 管理部署任务、服务器连接参数和远程脚本，避免反复手工输入服务器信息
- 将一次发布拆分为有顺序的步骤，并统一执行、记录日志和显示失败原因
- 支持任务、配置和脚本的创建、保存、复制、重命名、删除、自动暂存和拖拽排序

## 部署工作流能力

一个任务可以由以下步骤自由组合：

- **连接服务器**：读取已保存的服务器参数，建立 SSH 连接。
- **Git 合并分支**：拉取代码、合并指定分支、提交并推送。
- **Git 推送分支**：拉取代码、提交本地改动并推送。
- **Maven 打包**：执行 Maven 构建，自动识别或指定 JAR 产物，供后续上传使用。
- **本地命令 / 本地脚本**：在 Windows 本机执行准备、清理或构建命令。
- **上传文件或文件夹**：上传 Maven 产物、本地指定文件或整个目录到服务器；可自动创建远程目录。
- **上传前备份**：替换服务器旧文件前备份到指定目录，部署失败时可按流程恢复。
- **远程命令 / 远程脚本**：在服务器指定目录执行停止服务、解压、替换文件、启动服务等命令。
- **等待**：为服务停止、文件释放或进程启动预留等待时间。
- **健康检查**：循环执行检查命令，连续成功指定次数后才视为发布完成。

工作流支持执行日志、进度、超时、用户取消和失败提示。也可以在编辑器中右键某个步骤，从该步骤开始执行；前面的步骤会跳过，所需依赖未满足时会直接提示错误。

## 服务器操作能力

- 内置多标签 SSH 终端，可连接多个服务器并直接输入命令。
- 支持常用终端控制键、命令历史、复制粘贴、清屏、中断和重连。
- 内置 SFTP 双栏文件传输：左侧浏览本地目录，右侧浏览服务器目录。
- 可点击上传选中项、双击本地文件上传，或从本地列表、Windows 资源管理器拖拽文件和文件夹到右侧服务器目录。
- 上传完成后自动刷新服务器目录，并显示上传进度。

## 典型发布流程

例如，一个 Java 服务的发布任务可以配置为：

1. 连接测试或生产服务器。
2. 合并代码分支并推送。
3. Maven 打包生成 JAR。
4. 备份服务器上的旧 JAR，并上传新 JAR。
5. 执行远程停止和启动脚本。
6. 等待服务启动后执行健康检查。

## 环境要求

- Windows
- Python 3

## 安装依赖

在项目根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 启动

推荐直接双击或运行：

```powershell
.\start.bat
```

也可以使用虚拟环境直接启动 PySide6 入口：

```powershell
.\.venv\Scripts\pythonw.exe app\qt_main.pyw
```

在 PyCharm 中运行时，请将解释器设置为：

```text
.venv\Scripts\python.exe
```

运行脚本设置为：

```text
app\qt_main.pyw
```

## 配置文件

首次启动时，程序会自动创建 `conf/` 目录：

```text
conf/
├── tasks/          部署任务
├── parameters/     服务器连接参数
├── scripts/        部署脚本
├── .drafts/        编辑自动暂存
├── known_hosts     SSH 主机密钥记录
└── settings.json   界面设置
```

`conf/` 中可能包含服务器地址、账号或加密密码，因此默认已加入 Git 忽略规则，不建议提交。

## 打包

生成免安装版本：

```powershell
.\build.bat
```

输出目录：`release/DeployFlow/`

生成 Windows 安装包：

```powershell
.\build_installer.bat
```

输出目录：`installer-output/`。该操作需要 Inno Setup 6。

## 目录说明

- `app/`：应用程序和部署业务代码
- `assets/`：图标等资源文件
- `templates/`：新建服务器参数和脚本时使用的模板
- `installer/`：Windows 安装包配置
- `conf/`：本地任务与服务器配置，不提交 Git
