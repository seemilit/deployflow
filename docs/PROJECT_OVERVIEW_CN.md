# DeployFlow：让日常部署少一些重复操作

**面向个人开发者和小团队，把部署流程、SSH 终端、文件管理放在一起的 Windows 桌面工具。**

## 解决什么问题

只是发布几个项目，却要先搭建和维护一套完整的自动化部署平台，对个人和小团队来说可能有些重。

完全靠终端操作，又有另一种负担：本地打包后切换传输工具，上传后再切回终端找目录、执行脚本、查看日志。每次都重复同一组操作，步骤一多就容易遗漏。

DeployFlow 把这两部分工作放在同一个桌面窗口里：**把固定步骤保存成流程，把临时排查留在终端，把文件操作放在命令输出旁边。**

它不要求放弃已有的构建命令和脚本，而是将它们组织起来，让一次配置可以用于后续发布。

## 适合谁

- **个人开发者**：维护自己的服务，减少每次部署的重复操作。
- **小型研发团队**：保存清晰的发布步骤，减少对人工记忆的依赖。
- **需要自己部署的后端和前端开发者**：串联本地构建、上传、远程执行和检查。
- **经常操作 Linux 服务器的开发人员**：在一个窗口中查看终端、文件、服务器状态和日志。

这是面向桌面操作的部署工具，当前不提供集中调度、多人审批或分布式执行。

## 把发布步骤画出来，再按顺序执行

把“打包、连接服务器、上传、执行部署脚本、检查服务”组成可复用任务。节点可以编辑、拖动排序，也可以插入和删除；右侧直接显示对应参数。

![可视化流程和参数](screenshots/workflow.png)

支持 Git 操作、Maven 打包、本地命令与脚本、SSH 连接、文件上传、远程命令与脚本、等待和健康检查。

未选中节点时执行整个任务，选中后按原顺序执行选中的步骤；右键还可以单独执行某一步或从某一步开始。局部执行需要一并选中必要的连接、构建等前置步骤。

## 终端里的路径，不必再反复复制

这是 DeployFlow 的一个实用亮点：看到路径之后，可以直接继续操作。

- **按住 Ctrl，再把鼠标移到路径上**：可识别的路径显示下划线。
- **Ctrl＋左键点击目录**：终端工作目录和下方文件窗联动跳转。
- **Ctrl＋左键点击文件**：跳转到文件所在目录。
- **直接右键路径**：不必先选中文字；也支持选中文本后右键，识别后提供对应操作。

根据目标类型，可以打开文本编辑器、执行脚本并填写参数、修改权限，或跟踪日志、查看最后 N 行、搜索关键字。相对名称需要已有的目录上下文，路径也必须能在服务器上解析；各 SSH 页签分别维护自己的上下文。

![终端和文件目录联动](screenshots/remote-files.png)

## 服务器配置只填一次，常用位置直接连接

保存账号、地址、端口和认证方式，再为服务器配置常用目录及可选命令。下次可以直接连接到需要的位置。

![服务器配置和常用目录](screenshots/server-config.png)

支持密码保护与隐藏 IP。隐藏 IP 只改变支持的界面位置，不改变真实连接地址，也不保证遮蔽日志和任意远程输出。

## 终端、监控、文件传输放在一起

编辑任务时可以保留下方终端，也可以切换到完整终端模式。多页签管理连接，左侧显示 Linux 系统信息、CPU、内存、磁盘、运行程序和端口。

![终端模式和服务器状态](screenshots/ssh-monitor.png)

进程菜单支持停止及尝试重启。重启明确标为不建议，因为运行进程的信息未必能还原原始启动脚本、管道和日志重定向；需要保留这些行为时，应使用原脚本或服务管理器。

文件管理提供两种布局：终端下方的远程文件窗用于就地操作，独立的双栏 SFTP 窗口用于同时浏览本地磁盘与服务器目录。

![双栏 SFTP 文件管理](screenshots/sftp-transfer.png)

支持文件和文件夹上传下载、同一服务器连接标识内的复制／剪切／粘贴、重命名、删除、新建、权限修改及远程文本编辑。多个传输任务可以分别管理和取消，下载后可打开所在位置，也可以把远程文件拖到 Windows 资源管理器的目标文件夹下载。

## 脚本可复用，修改与执行有记录

在脚本页面集中保存已有脚本，再从流程引用，不需要把每次发布的命令重新写一遍。

![脚本编辑](screenshots/script-editor.png)

编辑内容自动暂存，点击保存后写入正式文件；历史版本支持预览、恢复和删除。在软件内重命名配置或脚本，会同步更新流程相关引用。

任务执行与 SSH 连接日志持续保存，按日期归档，文件名包含创建时间，记录带有时间戳。输出窗口清空后，仍能回看已保存的日志。

![日志记录](screenshots/logs.png)

## 用自己的语言和习惯操作

支持英语、简体中文、繁体中文、日语、韩语、西班牙语，首次默认英语，之后记住选择，无需重启即可切换。提供浅色、深色、纸张黄、护眼绿及自定义颜色，记录面板尺寸、流程缩放和文字大小。

配置、脚本、草稿、历史和日志保存在程序旁的 `conf/` 中，目录不存在时自动创建，需要对应写入权限。敏感数据应私下备份；密码加密与 Windows 用户绑定，跨电脑或账号迁移时可能需要重新填写。

**DeployFlow 的重点，是让常用的部署步骤可以重复执行，让临时的服务器操作少一点来回切换。**
