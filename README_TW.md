# DeployFlow

**整合視覺化部署流程、SSH 終端與 SFTP 檔案管理的 Windows 桌面工具。**

[English](README.md) · [简体中文](README_CN.md) · [繁體中文](README_TW.md) · [日本語](README_JA.md) · [한국어](README_KO.md) · [Español](README_ES.md)

## 為什麼使用 DeployFlow

對個人開發者與小型團隊而言，只部署幾個專案，也可能需要為完整的自動化部署平台投入額外的建置、設定與維護成本。完全依賴終端操作，又常要重複輸入指令、複製路徑、切換傳輸視窗，步驟一多就容易遺漏。

DeployFlow 將現有工具與腳本整理成可重複使用的桌面流程：建置、連線、上傳、執行腳本、健康檢查，再透過內建終端與檔案面板查看結果。

適合**個人開發者、小型研發團隊，以及經常部署或排查 Linux 伺服器的開發人員**。可用於 Java 服務發布、前端資源上傳與日常伺服器操作；目前不提供集中排程、多人審批或分散式執行。

![部署流程與步驟參數](docs/screenshots/workflow.png)

*範例：Maven 建置 → 連線 → 上傳 → 部署腳本 → 健康檢查。截圖使用英文介面，使用者內容與指令輸出保留原文。*

## 將發布清單變成流程

新增有順序的步驟，單擊查看參數、按兩下編輯、拖曳調整順序。選取節點後新增步驟會插入其後，未選取時則附加到末尾。流程與參數面板可分別或同時顯示。

| 步驟 | 用途 |
| --- | --- |
| 連線伺服器 | 載入設定，建立後續步驟使用的具名 SSH 連線。 |
| 合併／推送分支 | 按設定執行 Git 拉取、合併、提交與推送。 |
| Maven 建置 | 建置專案並辨識 JAR 產物，供上傳引用。 |
| 本機指令／腳本 | 設定工作目錄、逾時及腳本參數。 |
| 上傳 | 上傳產物、檔案或資料夾，可建立目標目錄並備份原有檔案。 |
| 遠端指令／腳本 | 使用指定連線執行指令或 Shell 腳本。 |
| 等待 | 暫停指定秒數。 |
| 健康檢查 | 重複執行檢查指令，達到連續成功次數後通過，逾時則失敗。 |

未選取節點時，**執行**會執行全部步驟；選取後僅依原順序執行選取項目。節點右鍵支援單獨執行及從此處開始。可查看輸出、進度、錯誤與逾時，並停止執行。

局部執行不會自動補跑相依步驟；請一併選取所需的連線或建置步驟。

## 終端路徑可以直接操作

- **Ctrl＋懸停**：游標下可辨識的路徑顯示底線。
- **Ctrl＋滑鼠左鍵**：目錄會同步跳轉終端與下方檔案面板；檔案則跳轉至所在目錄。
- **路徑右鍵**：可以先選取文字，也可以不選取而直接在路徑上按右鍵，辨識後提供對應操作。
- **檔案操作**：文字編輯、執行腳本與填寫參數、修改權限、持續追蹤日誌、查看最後 N 行及搜尋關鍵字。

路徑必須能在目前伺服器上解析；相對名稱需要已知的目錄資訊。各 SSH 分頁分別維護目錄上下文。

![終端與遠端檔案面板](docs/screenshots/remote-files.png)

## 伺服器設定與常用位置

使用表單管理位址、連接埠、帳號與認證。密碼與私鑰資訊可同時保留，由選取的認證方式決定使用哪一種。每台伺服器可儲存多組目錄與可選指令，設定預設位置，或直接連線至指定位置。

![伺服器設定](docs/screenshots/server-config.png)

提供密碼保護與**隱藏 IP**：支援的位址顯示可將 `192.168.10.25` 顯示為 `192.**.**.25`，實際連線仍使用原值。關閉隱藏後可編輯位址；此功能不會遮蔽已儲存日誌或任意遠端輸出。

## SSH 與即時伺服器資訊

透過分頁旁的 **+** 開啟其他已儲存的伺服器。可使用編輯頁面下方的終端，或切換終端模式取得較大的工作區。Qt WebEngine 與 xterm.js 提供終端顯示，支援 Shell 補全、歷史指令、複製貼上、中斷與重新連線。

側欄顯示 Linux 系統、核心、運行時間、負載、CPU、記憶體、交換空間、磁碟，以及程序的連接埠、資源占用與指令資訊。

![SSH 與即時監控](docs/screenshots/ssh-monitor.png)

程序右鍵支援停止與嘗試重新啟動。重新啟動標示為**不建議**，因為無法保證還原原始啟動腳本、管線及日誌重新導向；需要這些行為時，請使用原腳本或服務管理器。

## 兩種檔案管理方式

**雙欄 SFTP 視窗**左側為本機磁碟與目錄，右側為伺服器；可上傳選取項目，或從本機清單、Windows 檔案總管拖曳檔案與資料夾到遠端清單。

![雙欄檔案傳輸](docs/screenshots/sftp-transfer.png)

**內嵌遠端面板**位於終端下方，提供目錄樹、路徑導覽、歷史及檔案詳細資料，旁邊的日誌分頁顯示本次連線記錄。

支援上傳下載、遠端複製／剪下／貼上、重新命名、刪除、新增檔案與資料夾、權限設定及獨立文字編輯器。遠端剪貼簿限同一伺服器連線識別。傳輸面板可管理多個工作，刪除進行中的工作即可取消；下載完成後可開啟所在位置，也可拖曳遠端檔案至檔案總管中的資料夾以下載到該處。

## 腳本、歷史與日誌

集中儲存腳本並從流程引用。本機支援 `.bat`、`.cmd`、`.ps1`、`.sh`、`.bash`；遠端流程腳本使用 `.sh` 或 `.bash`。

![腳本編輯器](docs/screenshots/script-editor.png)

任務、設定與腳本支援自動暫存草稿，**儲存／Ctrl＋S**才寫入正式檔案。歷史版本支援預覽、還原、多選及刪除。在軟體內重新命名設定或腳本，會更新目前 JSON 流程、草稿與流程歷史的引用。

執行與 SSH 日誌按日期存放，檔名包含建立時間，記錄帶有時間戳記；清除畫面輸出後仍可從日誌頁面查看或刪除。

![已儲存的日誌](docs/screenshots/logs.png)

## 開始使用

需要 Windows 64 位元，目前開發環境使用 Python 3.12。遠端操作需要 SSH／SFTP，監控與遠端腳本主要面向 Linux。依步驟準備 Git、JDK、Maven 或 Maven Wrapper、Node.js／npm，以及本機 Shell 腳本所需的 Bash。

在專案根目錄執行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\start.bat
```

IDE 或直接啟動的入口：

```powershell
.\.venv\Scripts\python.exe app\qt_main.pyw
```

免安裝版本請保留完整目錄並執行 `DeployFlow.exe`。先儲存伺服器與腳本，再新增任務步驟、設定連線與產物引用、確認工作目錄，最後儲存並執行。

前端發布可使用：**本機腳本 → 連線 → 上傳資料夾 → 遠端指令 → 健康檢查**。批次檔的 `%CD%` 是目前工作目錄，`%~dp0` 是腳本所在目錄。

## 常用操作與外觀

| 區域 | 操作 |
| --- | --- |
| 流程 | 按兩下編輯，拖曳排序，Ctrl＋單擊多選，空白處拖曳框選。 |
| 畫布 | 滾輪縮放，按住右鍵拖曳平移。 |
| 編輯 | Ctrl＋S 儲存；參數／文字面板 Ctrl＋滾輪調整並記住字級。 |
| 遠端檔案 | Ctrl＋C／X／V、Delete、F2、Ctrl＋A。 |
| 歷史版本 | Ctrl＋單擊、Shift＋單擊、Ctrl＋A。 |

支援英語、簡體中文、繁體中文、日語、韓語、西班牙語。首次預設英語，之後使用儲存的選擇，切換不需重新啟動；使用者內容及外部輸出不翻譯。提供白、黑、紙張黃、護眼綠及自訂顏色，並記住面板尺寸、任務縮放與文字大小。

## 資料與注意事項

資料存於原始碼或 EXE 旁的 `conf/`，缺少的目錄會自動建立，因此該位置必須可寫入。

```text
conf/
├── tasks/          # version 2 JSON 流程，副檔名 .txt
├── host/           # 伺服器設定
├── scripts/        # 腳本
├── .drafts/        # 草稿
├── .history/       # 歷史版本
├── .logs/          # 按日期分組的日誌
├── .cache/         # 暫存
├── downloads/      # 預設下載目錄
├── known_hosts     # SSH 主機金鑰
└── settings.json   # 語言、外觀與偏好
```

- 不再支援舊 `STEP_xxx=...` 流程；軟體外重新命名不會同步引用。
- 伺服器預設位置與指令用於互動連線；流程的遠端工作目錄需另外設定。
- 上傳備份為可選項，後續失敗不會自動回復整個發布。
- 密碼加密綁定 Windows 使用者，跨電腦或帳號可能需要重新輸入。
- `conf/` 不納入 Git，請私下備份。隱藏 IP 不會移除日誌中的真實位址。

## 打包與授權

執行 `build.bat` 產生 `release/DeployFlow/`。安裝 Inno Setup 6 後，執行 `build_installer.bat` 產生 `installer-output/`；安裝後仍需確保 `conf/` 可寫入。

使用 PySide6、Qt WebEngine、xterm.js、Fabric／Paramiko。專案本身採用 [MIT License](LICENSE)，相依套件遵循各自授權；終端授權檔位於 [app/resources/xterm](app/resources/xterm/)。另有[簡體中文專案介紹](docs/PROJECT_OVERVIEW_CN.md)。
